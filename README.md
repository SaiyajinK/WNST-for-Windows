<p align="center">
WNST is a lightweight Windows utility that brings system, network, performance, maintenance, diagnostics, customization and software management tools together in one place.<br>
</p>

</p>
  <img width="700" height="1" src="https://via.placeholder.com/700x1/262626/262626">
</p>

### ✨ Features :

| Feature | Description |
| --- | --- |
| 📝 **Host** | Manage the hosts file, remote sources and automatic updates. |
| 💾 **History** | Browse, restore and delete hosts backups. |
| 🪟 **Windows** | Access maintenance, system, power and Winget tools. |
| ⚡ **Performance** | Optimize Defender, power, visuals, notifications and gaming. |
| 🧹 **Cleanup** | Manage installed and provisioned AppX packages with protection levels and filters. |
| 🩺 **Diagnostics** | Run DISM, SFC, CHKDSK, PATH and recovery tools. |
| 🛡️ **Advanced** | Manage OneDrive, telemetry, Edge and Windows AI. |
| 📡 **Network** | Diagnose connections, ports, DHCP, DNS and proxy settings. |
| 🔌 **Connections** | Inspect connections, processes and network adapters. |
| 🌐 **DNS** | Configure and test custom or preset DNS servers. |
| 🔥 **Firewall** | Manage inbound and outbound application rules. |
| 🎮 **Games** | Install official game launchers and apply reversible gaming tweaks.
| 📦 **Applications** | Install common applications, manufacturer tools and redistributables from official sources.
| 💻 **This PC** | View system details and configure connected displays. |
| 🎨 **Settings** | Customize themes, scaling, languages and local data. |
| ℹ️ **About** | View project information and check for updates. |

### 📘 Important information : 

<table>
  <tr><td>Administrator privileges are requested automatically when needed.</td></tr>
  <tr><td>Settings, backups and logs are stored in <code>%LocalAppData%\WNST</code>.</td></tr>
  <tr><td>The data location can be changed from Settings.</td></tr>
  <tr><td>Downloaded installers are stored in <code>%LocalAppData%\WNST\Downloads</code>.</td></tr>
  <tr><td>System tweaks are designed to be reversible.</td></tr>
  <tr><td>Sensitive operations require confirmation.</td></tr>
  <tr><td>Main system operations are logged.</td></tr>
  <tr><td>Logs and downloaded installers are preserved when resetting WNST.</td></tr>
  <tr><td>WNST does not disable UAC or modify the system PowerShell execution policy.</td></tr>
</table>
